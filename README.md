
# What is FOFO Paint?

<img width="600" alt="image" src="https://github.com/user-attachments/assets/56e79bdb-fad7-4c8e-a82e-304b81a41c4d" />


FOFO PAINT is painting application and freeware. developed with Adobe Air SDK.<br>
This app is for those who do not need complex features.

Features
- It's the Flash! feels of the 2000's Oekaki tool.
- 2 layers.
- Replay mode. You can watch the whole process like a movie, you can even go back to a specific point and redraw it.
- Unlimited undo, redo.

# 1. Download (version 30.0.0, 2026-11-26)
  [Download page (GitHub Releases)](https://github.com/guljam/2020FlashPaint/releases/latest)

- Windows: unzip and run `fofoPaint.exe`.
- Windows may show "Windows protected your PC" on the first run. Click "More info" → "Run anyway".
- Old versions (27.xx and earlier) are no longer supported. Save your work as a file in the old version before switching.
- [Release note](https://raw.githubusercontent.com/guljam/2020FlashPaint/refs/heads/master/releasenotev2.txt)


# 2. Install Adobe AIR Runtime (only for the .air file)
The `.air` file needs Adobe AIR runtime **51.4.1.2 or later**. The Windows zip files already include the runtime.

[https://airsdk.wxlift.com/runtime](https://airsdk.wxlift.com/runtime)

- If installing the `.air` fails because an old FOFO Paint (27.xx) is installed, uninstall the old FOFO Paint first and install again.

# 3. Manual
- Click the ? icon in the top menu on the initial window inside the app, then press the "Manual" button to check the guide page.
